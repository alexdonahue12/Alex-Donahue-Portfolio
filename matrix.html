Case Study

A Matrix Kinetic Type: Kinetic Type Motion Graphics

A Matrix-inspired kinetic type animation created in After Effects to explore motion design

Role
Motion Graphics,Typography, layout
Course
Typography 2
Deliverables
60-Second Kinetic Type Animation

Project brief

Project Brief: Create a kinetic typography animation that visually interprets a film scene using only type, synchronized with the original audio.

Design Approach: I designed a ~60-second kinetic type animation based on the red pill / blue pill scene from The Matrix. Using the scene’s original dialogue and sound, I relied solely on typography, scale, motion, rhythm, and timing, to communicate tension, choice, and narrative progression. The animation translates spoken words into visual emphasis, allowing type to carry the story while reinforcing the philosophical weight of the scene.
